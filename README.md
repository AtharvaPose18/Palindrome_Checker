# Palindrome String Checker
A simple Java program that checks whether a word reads the same forward and backward.

## Features
- Accepts a word from the user
- Reverses the entered word
- Checks whether the word is a palindrome
- Ignores uppercase and lowercase differences

## Technologies Used
- Java
- Scanner class
- For loop
- String methods
- If-else statements

## How to Run
1. Download PalindromeChecker.java.
2. Open a terminal in the folder containing the file.
3. Compile the program:
   javac PalindromeChecker.java
   
4. Run the program:
   java PalindromeChecker

## Example Output
Enter a word: Madam
It is a palindrome.

## Purpose
This project was created to practise Java fundamentals, string manipulation, loops, and conditional statements
